# 设计文档:全球地震带实时分布课件(earthquake-live)

日期:2026-09-13
状态:已获用户批准(2026-09-13)
定位:GeoBox 第 5 个预置课件;面试演示"杀手锏",讲述"教学问题 → 技术方案 → 课堂实效"的完整叙事

## 一、教学目标与依据

### 课标依据(普通高中地理课程标准,自然灾害主题)

- 3.2 解释地震、泥石流、滑坡等地质灾害的成因与危害
- 3.6 运用图表资料,说明世界主要自然灾害的空间分布
- 3.9 以地震等自然灾害为例,列举适当的应对方法或应急措施
- 3.10 说明地理信息技术在自然灾害预测、灾情监测和评估中的运用(数据来源与更新时间的常驻展示即是活教材)

### 学情依据(文献调研结论)

- 学生对地震成因存在顽固迷思概念:约 32% 认为"板块碰撞=地震",41% 认为"板块摩擦",仅约 2% 能正确表述"应力积累→断裂突然释放"
- 常见迷思:"海岸线 = 板块边界"、"火山分布在赤道等高温地区"
- 困难根源:地质过程的时空尺度超出直接经验,无法直接观察
- 教学启示:以近期真实地震作为情境导入效果最好;可视化必须服务于"可观察 → 可归纳 → 可解释"的认知链

### 适用场景

人教版必修第一册"地质灾害"(6.2);希沃白板大屏投影授课;教师触控操作。

## 二、教学动线:四个环节(分环节引导型)

顶部环节页签,切换环节时自动切换图层与高亮;每个环节内保留自由探索(点击、筛选、缩放)。

| 环节 | 画面状态 | 教师引导要点 |
|---|---|---|
| ① 观察 | 世界地图 + 所选时间范围(24h/7d/30d)的真实地震点;最新地震涟漪脉冲;顶部滚动条播报最近地震 | "这是过去 24 小时真实发生的地震"——情境导入 |
| ② 规律 | 切到 30 天数据,点密度增大;引导学生观察分布形态 | 分布不均匀,呈带状;纠正"海岸线=板块边界"迷思 |
| ③ 成因 | 板块边界图层沿走向流光扫过式淡入;地震带与板块边界高度重合;点击地震弹出详情卡(震级、震源深度、所在边界类型:消亡/生长/转换) | 地震带 = 板块边界;渗透"应力积累→断裂释放"正确概念 |
| ④ 防震 | 视图聚焦中国及周边;叠加中国地震带;震级 vs 烈度辨析卡;应急要点 | 人地协调观落点,课标 3.9 |

## 三、数据策略(真实 + 离线兜底)

- **实时源**:USGS Earthquake Hazards Program 官方 GeoJSON feed(免费、无需 API key、分钟级更新,全球含中国);三档:过去 24 小时 / 7 天 / 30 天
- **板块边界**:PB2002 板块边界数据(Bird 2003,学术界标准),内置为精简 GeoJSON(`plates.min.geojson`,渲染用,单色);边界类型(消亡/生长/转换)不在这份文件里——其 `LAYER` 属性是常量,实际类型只在同数据集的 `PB2002_steps.json`(`STEPCLASS` 字段)里,故额外内置 `plate-steps.json`(分段中点采样)供详情卡按最近点查类型
- **离线兜底(硬需求,希沃白板常断网)**:
  - 包内置一份近 30 天真实地震快照(打包时抓取)
  - USGS 拉取成功 → 覆盖并通过 `window.geobox.storage` 持久化缓存;拉取失败 → 回退到上次缓存,再退到内置快照
  - 数据来源(USGS)与实际数据时间常驻角标
- **中国地震带**:内置中国地震带矢量(公开出版资料整理)

## 四、双视图

- **2D 世界地图(主视图)**:等距圆柱投影,复用时区换算器的 Natural Earth 底图与 Canvas 2D 渲染栈;平滑平移缩放
- **3D 地球(右上角切换)**:复用晨昏线课件的 three.js 地球与贴图;惯性自转 + 拖拽阻尼(dampingFactor 0.1),旋转/缩放速度随相机高度自适应(rotateSpeed = altitude × 0.2);地震点以 HTML 标记层(CSS2DRenderer 思路)叠在球面上
- 视图切换时镜头平滑过渡,非生硬跳变

## 五、视觉与动效系统

- **基调**:与 GeoBox 主程序一致的白色主题;底图低饱和,数据点高饱和,确保投影可读性
- **地震点语义色阶**(由琥珀 #fbbf24 / 红 #f87171 色系派生,适配白底):小震琥珀、中强震橙红、强震红;最新地震高亮
- **标志性动效**:
  1. 最新地震的同心圆涟漪扩散(暗合地震波自震中传播)
  2. 环节切换图层编舞:板块边界沿走向以 stroke-dashoffset 流光扫过式绘出
  3. 地震点按时间顺序级联点亮(stagger),直观呈现"这段时间地球在震颤"
  4. 顶部最近地震滚动条,悬停/触摸暂停
- 尊重 `prefers-reduced-motion`;低配机自动降级(减少粒子/关闭环境动画)
- 中文字体走系统栈,禁用中文斜体

## 六、技术方案与边界

- 形态:标准 `.gpak` 课件包,源码置于 `courseware/earthquake-live/`,播种进预置库(版本 1.0.0)
- 2D:Canvas 2D;3D:three.js(运行时由 postinstall 复制,不入库)
- 桥接:`window.geobox.storage` 缓存地震数据;不新增主程序 API
- **不做(YAGNI)**:历史大地震时间轴(唐山/汶川复盘)、地震波传播模拟、滑坡/泥石流内容、学生端互动

## 七、错误处理

- 网络失败 → 缓存 → 快照,三级回退均有角标注明数据日期,不弹窗打断授课
- 数据字段缺失(如震源深度) → 详情卡对应字段显示"—",不崩溃
- WebGL 不可用 → 自动隐藏 3D 切换入口,2D 完整可用

## 八、测试与验收

1. 断网冷启动:快照数据正常渲染,角标日期正确
2. 弱网/超时:回退路径无报错、无弹窗
3. 四个环节切换:图层编舞正确、状态不串
4. 触控:点标记出详情卡、拖动/缩放两个视图
5. 低配机(禁用 GPU 软件渲染)帧率可接受
6. 截图走查:白底投影可读性(文字对比度)

## 九、简历叙事锚点

该课件支撑的面试故事:"研究发现学生对地震成因存在迷思概念(仅约 2% 能正确表述),且地质过程时空尺度不可直接观察;因此开发接入 USGS 实时数据的交互课件,以'观察→规律→成因→防震'四环节引导,把不可见的过程变成可观察的规律。"
